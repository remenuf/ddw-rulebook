## Directory Overview
This project contains the documentation and assets for **DDW 2ª Edição**, a tabletop RPG system focused on narrative gameplay with resource management. It is a non-code project, primarily consisting of Markdown documentation and image assets.

The system is inspired by *Fate*, *Chuubo’s Marvelous Wish-Granting Engine*, and various Manwhas, aiming for a simple yet functional mechanical core that preserves the essence of the original DDW.

## Key Files
- **`rulebook.md`**: The primary document of the project. It outlines the entire game system, including:
    - **Attributes**: Causalidade (Causality), Arcanismo (Arcanism), Proeza Marcial (Martial Prowess), Fé (Faith), and Genialidade (Genius).
    - **Skills (Habilidades)**: Player-created traits that define proficiency.
    - **Action Mechanics**: Spending Action Points (PA) per scene to perform actions with varying degrees of success.
    - **Talents**: Specialized abilities (Magic, Martial, Miraculous, etc.) that define a character's unique powers.
    - **Combat**: Rules for offense, defense, stress, and consequences.
    - **Progression**: Leveling from 1 to 8 through narrative milestones and the concept of "Convergence."
    - **Equipment & Consumables**: Rules for item levels, durability, and usage limits (overdose).
- **`DDW 2ª Edição/`**: A subdirectory containing all the image assets (PNG, SVG) referenced within `rulebook.md`.

## Usage
This directory serves as the central repository for the DDW 2ª Edição ruleset. Use `rulebook.md` as the source of truth for all game mechanics, character creation, and world-building guidelines. When interacting with this project, ensure that any additions or modifications to the rules remain consistent with the established narrative-first philosophy.

## Writing Style & Conventions
- **Macro-level Heading Structure**: Headers (`#`, `##`) are reserved for major sections. Avoid excessive sub-headings for every minor concept; use bold text or tables instead to maintain a clean flow.
- **Minimalist Lists**: Bullet points are used sparingly and kept flat. Avoid deep nesting. They are primarily for lists of items, examples, or simple categories.
- **Tabular Mechanics**: Tables are the preferred method for representing progression, difficulty levels, action results, or any data-heavy mechanics.
- **Contextual Containers**: Use `<aside>` blocks for meta-commentary, specific rules, warnings, or flavor text that sits outside the main instructional flow.
- **Narrative & Informal Tone**: The writing is conversational and addresses the player directly (e.g., using "você"). It often includes meta-references and humor.
- **Visual Separation**: Use horizontal rules (`---`) and frequent images to break up text and separate major conceptual shifts.
- **Direct Definitions**: Concepts are defined in brief, direct sentences or paragraphs rather than long, academic explanations.
